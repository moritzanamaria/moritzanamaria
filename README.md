# 🚀 Anamaria's Frontend Launchpad

Bok! Ja sam **Anamaria**, polaznica edukacije za Frontend Developera u Edunovi (Osijek). 
Ovaj repozitorij je moja digitalna radna bilježnica u kojoj pratim svoj napredak.

### 🛠️ Što sam do sada savladala?

### 🐙 Git & GitHub (Verzioniranje)
* **Osnovni workflow:** git clone, git push i git pull.
* **Pojmovi:** Razumijem razliku između Centraliziranih i Distribuiranih sustava te kako GitHub služi kao platforma za pohranu repozitorija.
* **Alati:** Uspješno koristim Command Prompt i VS Code.

### 🌐 HTML (Struktura)
* **Anatomija dokumenta:** Razumijem ulogu DOCTYPE, head (metapodaci) i body sekcija.
* **Validacija:** Provjeravam ispravnost koda putem W3C Validatora.

### 🎨 CSS (Vizualni izgled)
* **Povezivanje:** Znam napraviti CSS datoteku i povezati ju s odgovarajućim HTML-om.
* **Osnove:** Selektori, kaskadnost i mjerni sustavi.

### 📜 JavaScript (Interaktivnost)
* **Osnove jezika:** Varijable, tipovi podataka, uvjeti, petlje i funkcije.
* **Rad s DOM-om:** Dohvaćanje i mijenjanje elemenata, reagiranje na događaje (event listeneri).
* **Strukture podataka:** Rad s poljima i objektima.
* **OOP u JavaScriptu:** Klase, konstruktori, nasljeđivanje i metode.

### ⚛️ React (U tijeku)
Sljedeći korak — prelazak s "obične" stranice na komponentnu web aplikaciju:
* Komponente i JSX
* Props i state
* Gradnja interaktivnog sučelja
